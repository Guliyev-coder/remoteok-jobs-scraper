# RemoteOK Jobs Scraper (All Categories & Full Data)

Fast, lightweight scraper for **RemoteOK.com** built on Apify. Extract all active remote job listings across every category or filter by specific tags (`python`, `ai`, `devops`, `marketing`, `design`) and keywords in seconds.

[![Run on Apify](https://apify.com/actor-badge?actor=guliyev/remoteok-jobs-scraper)](https://apify.com/guliyev/remoteok-jobs-scraper)

## What Data It Extracts
- Job Title (`position`), Company Name (`company`), & Company Logo (`companyLogo`)
- Salary Range (`salaryMin`, `salaryMax`) & Location (`location`)
- Category Tags (`tags`), Posting Date (`datePosted`), & Verification Status (`verified`)
- Direct Job URL (`url`) & Application Link (`applyUrl`)
- Clean Plain-Text Description (`descriptionText`) + Optional Raw HTML (`descriptionHtml`)
